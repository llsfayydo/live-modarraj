## ✨ المميزات

### واجهة مستخدم
- 🌙 **واجهة داكنة فخمة** - تصميم احترافي بألوان ذهبية وزرقاء
- 📱 **متجاوبة** - تعمل على جميع الأجهزة (الهاتف، التابلت، الكمبيوتر)
- 🌍 **متعددة اللغات** - دعم كامل للغة العربية

### المباريات والبيانات
- ⚽ **8 دوريات رئيسية:**
  - English Premier League (الدوري الإنجليزي)

  - Bundesliga (الدوري الألماني)
  - Saudi Professional League (الدوري السعودي)
  - Egyptian Premier League (الدوري المصري)

- 🔄 **تحديث فوري** - بيانات حية كل 30 ثانية
- 📡 **اتصال Socket.io** - اتصال ثنائي الاتجاه للتحديثات الفورية
- ⏱️ **مؤقت العد العكسي** - عرض الوقت المتبقي قبل بدء المباراة

### الأداء والموثوقية
- 💾 **كاش ذكي** - تخزين مؤقت لتسريع التحميل
- 🔐 **معالجة أخطاء متقدمة** - استعادة تلقائية عند فشل الاتصال
- 📊 **بيانات عينة احتياطية** - عرض بيانات تجريبية عند عدم توفر البيانات الحقيقية

## 🚀 التثبيت

### الخطوة 1: نسخ المستودع
```bash
git clone https://github.com/llsfayydo/live-modarraj.git
cd live-modarraj
```

### الخطوة 2: تثبيت المتطلبات
```bash
npm install
```

هذا سيقوم بتثبيت المكتبات التالية:
- ✅ express - إطار العمل الويب
- ✅ socket.io - الاتصال الفوري
- ✅ axios - طلبات HTTP
- ✅ mongoose - قاعدة البيانات (اختياري)
- ✅ dotenv - إدارة متغيرات البيئة

### الخطوة 3: إنشاء ملف الإعدادات
```bash
# انسخ ملف المثال
cp .env.example .env

# أو أنشئ ملف .env جديد بالمحتوى التالي
```

## ⚙️ الإعدادات

### ملف `.env`

أنشئ ملف باسم `.env` في جذر المشروع بالمحتوى التالي:

```env
# 🔑 مفتاح TheSportsDB API (المدفوع)
THESPORTSDB_API_KEY=5010468507

# 🚀 منفذ التطبيق
PORT=5000

# 🌍 بيئة التطبيق
NODE_ENV=development

# 🔐 قاعدة البيانات MongoDB (اختياري)
MONGODB_URI=mongodb://localhost:27017/live-modarraj

# 💾 مدة الكاش بالميلي ثانية
CACHE_TTL=60000

# 📡 أصول CORS المسموح بها
SOCKET_IO_ALLOWED_ORIGINS=*
```

### ملف `.gitignore`

**⚠️ تأكد من أن ملف `.env` في `.gitignore`** لتجنب رفع بيانات حساسة:

```
.env
node_modules/
logs/
.DS_Store
```

## 🏗️ البنية المعمارية

### مخطط الملفات

```
live-modarraj/
├── 📄 server.js                      # السيرفر الرئيسي (Node.js + Express)
├── 📄 live_modarraj_frontend.html   # الواجهة الأمامية (HTML + CSS + JS)
├── 📄 package.json                  # معلومات المشروع والمتطلبات
├── 📄 .env.example                  # قالب متغيرات البيئة
├── 📄 .gitignore                    # الملفات المستثناة من Git
└── 📄 README.md                     # هذا الملف
```

### تدفق البيانات

```
المتصفح (Frontend)
    ↓
fetch() HTTP Request
    ↓
Server.js (Express)
    ↓
axios.get() TheSportsDB API
    ↓
معالجة البيانات وتحويلها
    ↓
رد JSON للمتصفح
    ↓
عرض المباريات في الواجهة
    ↓
Socket.io تحديثات فورية
```

### المكونات الرئيسية

#### Backend (Server.js)
- **Express:** خادم الويب
- **Socket.io:** اتصالات فورية
- **Axios:** طلبات HTTP لـ TheSportsDB
- **Mongoose:** قاعدة بيانات (اختياري)
- **Dotenv:** إدارة المتغيرات

#### Frontend (HTML/CSS/JS)
- **HTML:** هيكل الصفحة
- **CSS:** تصميم واجهة مستخدم
- **JavaScript:** منطق التطبيق وتفاعل المستخدم
- **Socket.io Client:** اتصالات فورية

## 🔧 استكشاف الأخطاء

### المشكلة: "لا توجد مباريات"

**الحل:**
1. تحقق من التاريخ المطلوب (قد لا توجد مباريات في هذا التاريخ)
2. تحقق من اتصالك بالإنترنت
3. تحقق من صحة مفتاح API في `.env`

```bash
# اختبر الاتصال مباشرة
curl "http://localhost:5000/api/matches?date=2026-08-12"
```

### المشكلة: "Error 404 - الرابط المطلوب غير موجود"

**الحل:**
1. تأكد من تشغيل السيرفر: `npm start`
2. تحقق من المنفذ الصحيح (افتراضي: 5000)
3. تأكد من رابط الواجهة الأمامية

```bash
# تحقق من حالة السيرفر
curl "http://localhost:5000/api/health"
```

### المشكلة: "Failed to load resource: net::ERR_CONNECTION_REFUSED"

**الحل:**
1. تأكد من تشغيل السيرفر
2. تحقق من المنفذ المستخدم

```bash
# شغّل السيرفر
npm start

# أو في وضع التطوير
npm run dev
```

### المشكلة: "API key is not valid"

**الحل:**
1. تحقق من مفتاح API في ملف `.env`
2. تأكد من نسخ الرقم بشكل صحيح: `5010468507`

```env
# الصحيح
THESPORTSDB_API_KEY=5010468507

# الخطأ
THESPORTSDB_API_KEY=invalid_key
```

### المشكلة: "Cannot find module 'dotenv'"

**الحل:**
```bash
# أعد تثبيت المتطلبات
npm install
```

# اجعل المتصفح مفتوحاً على أدوات المطور (F12)
# انظر إلى تبويب "Console" للرسائل التفصيلية

# أو انظر إلى سجلات السيرفر
